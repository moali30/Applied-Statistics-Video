# فيديوهات شرح الإحصاء التطبيقي (SAT301)

فيديوهات animation لشرح سكاشن الإحصاء التطبيقي بالعامية المصرية، بصوت المعيد.

## خطوات كل سكشن

1. البرزنتيشن بتاع السكشن هو المصدر.
2. اسكريبت مقسّم لمقاطع مترقمة (`script/`)، وكل مقطع فيه الكلام اللي هيتقال ووصف للي هيظهر على الشاشة.
3. تسجيل صوتي لكل مقطع في ملف لوحده.
4. فيديو animation متظبط على الصوت.

## الملفات

- `script/section-01-script.md`: اسكريبت سكشن 1 (المعاينة)، وده الأصل اللي بيتعدّل.
- `script/section-01-script.html`: نفس الاسكريبت في صفحة سهلة القراية وقت التسجيل.
- `tools/script_to_html.py`: بيحوّل الاسكريبت لصفحة HTML:

```
python3 tools/script_to_html.py script/section-01-script.md script/section-01-script.html
```
